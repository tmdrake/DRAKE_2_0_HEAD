# DRAKE_2_0_HEAD

ESP8266 head firmware — SoftAP, ESP-NOW, modes 0–10, CDS eyes, fan.

## Repo policy

**No binary files** in git (PDF, images, firmware blobs). Datasheets stay local or on a wiki.

## Modes

0–10 non-blocking; CDS dims eye pixels 0–3. See Tail [SYSTEM.md](https://github.com/tmdrake/DRAKE_2_0_TAIL/blob/main/SYSTEM.md).
